# Why there is no front end

The daily job is a brief, exact wording, supporting evidence and a recorded decision. An operator can manage that through one CLI and ask Claude Code, Codex, OpenCode or Cursor to do the work.

npm run view creates read-only HTML snapshots. npm run docs creates branded draft approval packs and launch worksheets. brand.json supplies the business name, logo and colours. These files do not provide editing controls or a shared portal.

A screen provides visual annotations, drag and drop, mobile capture and simultaneous collaboration that this base does not. It also does not scan images or websites for claims. Review complete creative files in the tools the team already uses. Store their version references here. Connected proofing, authenticated approvals and a web interface are custom work through Omni by Enterprise DNA.
